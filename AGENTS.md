# Especificação para agentes

## Propósito do repositório

Este repositório é uma coleção de scripts, cada um com uma responsabilidade clara. Scripts podem ser combinados — por exemplo, um pode usar outro — quando tiverem propósitos relacionados. Essa combinação é opcional; mantenha-os independentes quando não houver benefício claro na integração.

## Regras gerais

- Todo script que precisar receber o caminho de um arquivo deve permitir informá-lo por argumentos de linha de comando.
- Mantenha cada script focado em sua responsabilidade e evite acoplamento desnecessário.
- Documente de forma clara os argumentos e parâmetros de cada script.

## README

O README de cada projeto deve ser escrito em português e usar uma estrutura simples, contendo:

1. **Explicação resumida** do que o script ou projeto faz.
2. **Pré-requisitos e instalação**, com dependências e instruções para preparar o ambiente.
3. **Como usar**, descrevendo argumentos e parâmetros e incluindo exemplos de uso.
